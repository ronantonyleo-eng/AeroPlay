## Overview

AeroPlay is a personal customization of SimpMusic that introduces a new visual identity and a redesigned user interface. The project combines the original application's foundation with a distinctive aesthetic inspired by glossy metallic surfaces, glass-like elements, atmospheric backgrounds, and Y2K-era design.

The goal is to create a more personalized music-listening experience while retaining the functionality of the original project wherever possible.

## Features

- Custom AeroPlay branding, application name, and launcher icons.
- Frutiger Aero-inspired visual design.
- Y2K-inspired interface elements and styling.
- Custom backgrounds and artwork presentation.
- Personalized home screen and navigation interface.
- Android application built with Kotlin and Compose Multiplatform.

## Building from Source

### Requirements

- Git
- A compatible Java Development Kit
- Android SDK
- Windows, macOS, or Linux with the required build tools

### Clone the Repository

```bash
git clone https://github.com/ronantonyleo-eng/AeroPlay.git
cd AeroPlay
```

### Build the Android Debug APK

On Windows, run:

```powershell
.\gradlew.bat :androidApp:assembleDebug
```

On macOS or Linux, run:

```bash
./gradlew :androidApp:assembleDebug
```

After a successful build, APK files are generated in:

```text
androidApp/build/outputs/apk/debug/
```
